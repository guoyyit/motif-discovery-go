# motif-discovery-go

本地核酸序列模体发现与统计显著性评估服务。给定一组 FASTA 核酸序列，
服务从中发现显著富集的短序列模式（以位置权重矩阵 PWM 表示），并给出
经验 p 值、多重检验校正结果与显著性结论。**所有随机过程由显式种子控制，
固定种子与相同输入下输出逐位一致**，与并发调度、是否中断无关。

## 快速开始

```go
seqs, err := motif.ParseFASTAStr(fastaText)

cfg := motif.DefaultConfig()
cfg.MotifLength = 10      // 模体长度 L
cfg.ExpectedCount = 1     // 期望模体数量 K
cfg.InitRounds = 40       // 多轮初始化轮数
cfg.Seed = 42             // 显式随机种子

result, err := motif.Discover(seqs, cfg)
for _, m := range result.Motifs {
    fmt.Println(m.Consensus, m.PValue, m.AdjustedP, m.Significant)
}
```

## 功能与实现要点

### 1. FASTA 解析

- `ParseFASTA` / `ParseFASTAStr`：支持大小写混用（内部统一大写）、
  `;` 注释行、空行与序列行内空白；`>` 头记录含名称与描述。
- 仅接受碱基 `A/C/G/T`；非法字符、缺失序列数据、数据出现在头之前等
  格式问题一律返回 `*ParseError`，带 **1 起始行号与列号**。

### 2. 位置权重矩阵（PWM）

- `BuildPWM(sites, bg, cfg)`：由等长对齐片段 + 四核苷酸背景构建加性
  对数似然比（LLR）矩阵，含 Dirichlet 式伪计数（默认 0.8，按背景加权）。
- `PWM.Score` 为相对背景模型的原始 LLR 得分；
  `PWM.NormalizedScore` 用该矩阵的理论最小/最大得分线性归一化到 `[0,1]`。
- `PWM.Scan` / `ScanAll(seq, threshold)`：滑动扫描并返回达到
  **可配置归一化阈值** `PWMConfig.Threshold`（默认 0.8）的命中。
- 背景模型 `Background` 为 (A,C,G,T) 概率，`DefaultConfig` 使用经验
  单核苷酸频率（零频率做小量平滑）；也可使用 `UniformBackground()`。

### 3. 参数化模体发现

`Config` 完整控制发现流程（默认值见 `DefaultConfig`）：

| 配置项 | 含义 | 默认 |
| --- | --- | ---|
| `MotifLength` | 模体长度 L | 10 |
| `ExpectedCount` | 期望模体数量 K（顺序抽取，掩码已选位点） | 1 |
| `InitRounds` | 初始化轮数，输出信息含量最高的最优结果 | 20 |
| `ConvergenceTol` | EM 收敛容差（平均得分相对变化） | 1e-4 |
| `MaxEMIterations` | 单轮 EM 最大迭代次数 | 100 |
| `PWM.Pseudocount` | PWM 伪计数 | 0.8 |
| `PWM.Threshold` | 归一化打分阈值（[0,1]） | 0.8 |
| `Filter.*` | 低复杂度/重复过滤（见下） | 开启 |
| `Significance.Permutations` | 随机重排零分布次数 B | 100 |
| `Significance.Alpha` | 校正后显著性阈值 | 0.05 |
| `Significance.Method` | 多重检验校正方法 | `"BH"` |
| `Seed` | 控制一切随机过程的 64 位种子 | 1 |

发现算法为两阶段 MEME 式硬分配 EM：

1. **侦察阶段**：构建所有候选窗口的 k-mer 出现索引，以“该精确窗口在
   其余序列中的出现序列数”为廉价富集代理，挑选最有希望的 `InitRounds`
   个种子（不足则确定性随机补足），保证真实富集窗口一定进入候选；
2. **收敛阶段**：从每个种子构建锚定主导的初始 PWM，迭代“每条序列取
   归一化得分最高位点（E 步）→ 由位点重建 PWM（M 步）”直到分配稳定
   或满足容差；
3. 多轮中取 **PWM 总信息含量** 最大的结果；K>1 时掩码上一模体的位点
   邻域后顺序抽取。

### 4. 统计显著性语义（重要）

- 检验统计量为发现模体的 **PWM 总信息含量（比特）**，衡量各位置的
  碱基保守性。这一指标在“挑选最优模体”的完整选择过程下仍然可校准。
- 零假设 H0：序列间不存在共享的位置特异信号，仅碱基组成存在。每次
  重排使用 Fisher–Pitman 式**组成保留随机重排**（Fisher–Yates 打乱
  每条序列，保持 A/C/G/T 计数不变），并在重排数据上**重新运行完整的
  多轮发现流程**。因此零分布自动包含“从数据中事后挑选最优模体”的
  赢家诅咒，避免了“用固定矩阵打分”导致的反保守偏差。
- 经验 p 值使用 +1 校正：
  `p = (1 + #{零分布统计量 >= 观测}) / (1 + B)`，故最小可达 p 值为
  `1/(1+B)`，永不返回 0。
- K>1 时采用**顺序检验**：观测第 k 个模体与每次重排重新发现的第 k 个
  模体比较（上一槽位的位点在重排中同样被掩码）。
- 多重检验使用 **Benjamini–Hochberg FDR** 校正（`BHAdjust`），
  返回与输入等长、等序的 q 值；`Motif.Significant = q <= Alpha`。
- 若需要更细的 p 值分辨率，提高 `Significance.Permutations`
  （显著性阈值与 B 的关系需满足 `1/(1+B) <= Alpha`）。

### 5. 低复杂度与重复序列处理

`ComplexityFilter`（默认开启）在三层防护，确保简单重复不被误报：

- **区域掩码**：单碱基连续延伸（默认 ≥8 bp）、周期 2–4 的串联重复
  （默认 ≥10 bp，排除退化单元与更小周期解释）、12 bp 滑窗香农熵
  < 1.0 bit 的区域被标记；`AllowedStarts` 排除与掩码区域重叠的窗口。
- **位点自检**：`SitePasses` 拦截自身呈周期 1–4 重复或低熵的片段。
- **统计层面**：重排保留碱基组成，高 AT/重复背景在零分布中同样常见，
  因而重复模式不会获得显著 p 值。

### 6. 并发隔离与可复现性

- 随机源 `RNG` 基于 SplitMix64，无全局状态、不依赖 goroutine 调度或
  map 迭代顺序；每个（槽位、轮次、重排编号）都由 `Seed` 确定性派生
  独立随机流（`StreamFromSeed`）。
- `TaskManager` 支持多个发现任务并发运行，任务之间输入、配置、检查点
  完全隔离；同一任务固定种子无论并发还是顺序执行，结果逐位一致。

### 7. 中断与恢复

- 每个初始化轮次与每次随机重排完成后立即更新 `Checkpoint` 并
  **原子落盘**（临时文件 + rename）。
- `Pause` 在最近的检查点边界生效；暂停期间不暴露任何部分最终结果。
- `Resume` 跳过已完成的轮次/重排编号，**不产生部分结果、不重复计算**；
  最终输出与不中断运行逐位一致。检查点为 JSON，可跨进程保存/加载
  （`Checkpoint.Save` / `LoadCheckpoint` / `SubmitResumable`）。
- 配置与种子通过 SHA-256 摘要校验，配置不一致的检查点拒绝恢复。

## 测试

`go test ./...`（建议加 `-race`）覆盖：

- FASTA 解析的合法/非法用例与错误位置；
- PWM 构建、归一化打分、扫描与背景校验；
- RNG 确定性、均匀性与组成保持打乱；
- 低复杂度/串联重复掩码与位点拦截；
- BH 校正与经验 p 值（含并列、+1 校正）；
- **合成植入模体的位点级召回率**（5 组独立数据，召回率 ≥ 0.8，
  实测 1.0）；
- **显著性校准**：纯随机序列在 α=0.05 下不显著；
- **低复杂度过滤**：AT 重复植入不被报为显著；
- **可复现性与并发隔离**：同种子逐位一致、异种子不同、并发=顺序；
- **中断恢复**：内存与磁盘检查点两条路径，恢复结果等于不中断结果，
  且竞态检测通过。
